# SecurePass 🔐

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Beginner-success)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

SecurePass is a command-line password generator built with Python. It creates strong, customizable passwords by allowing users to choose the desired password length and the types of characters to include.

---

## Features

- Custom password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Input validation
- Replay option
- Modular code organization

---

## Concepts Practiced

- Random Module
- String Module
- Lists
- Functions
- Input Validation
- Modular Programming
