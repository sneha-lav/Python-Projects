# Math Sprint 🧮⏱️

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

A command-line math challenge game where players solve randomly generated arithmetic problems against the clock. Test your speed, accuracy, and mental math skills while tracking your performance.

---

## Features

- Timed gameplay
- Random arithmetic questions
- Multiple difficulty levels
- Score tracking
- Accuracy calculation
- Replay option
- Modular code organization

---

## Concepts Practiced

- Random Module
- Time Module
- Loops
- Functions
- User Input
- Conditional Statements
- Modular Programming
