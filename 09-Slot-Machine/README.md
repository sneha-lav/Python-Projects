# Lucky Spin 🎰

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

A command-line slot machine game built with Python where players can place bets, spin the reels, and win virtual coins based on matching symbols. The project focuses on randomization, game logic, input validation, and balance management.

---

## Features

- Virtual coin balance
- Deposit system
- Betting system
- Random slot spins
- Multiple winning combinations
- Payout calculation
- Replay option
- Modular code organization

---

## Concepts Practiced

- Dictionaries
- Lists
- Random Module
- Functions
- Loops
- Input Validation
- Conditional Statements
- Modular Programming
