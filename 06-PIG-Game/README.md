# Binary Search Visualizer 🔍

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

A command-line application that demonstrates the Binary Search algorithm by efficiently locating a target value within a sorted list. The project highlights algorithmic thinking, recursion, iteration, and performance optimization.

---

## Features

- Search for a target number in a sorted list
- Displays search progress step-by-step
- Reports the number of iterations taken
- Handles values that are not found
- Modular code organization
