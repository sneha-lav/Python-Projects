# HoopHub 🏀

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

HoopHub is a Python application that fetches live NBA game scores and standings using the NBA API. It allows users to stay updated with ongoing games, final scores, and team information directly from the terminal.

---

## Features

- Live NBA scores
- Game status (Scheduled, Live, Final)
- Team names
- Team scores
- Current standings
- Error handling
- Modular code organization

---

## Concepts Practiced

- REST APIs
- JSON Parsing
- HTTP Requests
- Error Handling
- Functions
- Modular Programming
