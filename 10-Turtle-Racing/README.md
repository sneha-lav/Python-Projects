# Turtle Grand Prix 🐢🏁

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

A graphical turtle racing game built using Python's Turtle graphics library. Players predict the winning turtle before the race begins and watch the turtles compete with randomized movements.

---

## Features

- Graphical race simulation
- Six colorful turtles
- Player prediction system
- Randomized movement
- Race results
- Replay option
- Modular code organization

---

## Concepts Practiced

- Turtle Graphics
- Random Module
- Loops
- Lists
- Functions
- User Input
- Event-driven Programming
