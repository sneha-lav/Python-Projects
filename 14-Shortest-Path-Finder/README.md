# PathFinder 🗺️

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

PathFinder is a command-line application that finds the shortest path between two locations in a weighted graph using Dijkstra's Algorithm. It demonstrates how graph traversal and pathfinding algorithms are used in navigation systems.

---

## Features

- Weighted graph representation
- Dijkstra's Algorithm
- Finds shortest distance
- Displays shortest route
- Input validation
- Modular code organization

---

## Concepts Practiced

- Graphs
- Dictionaries
- Priority Queue (Heap)
- Dijkstra's Algorithm
- Functions
- Modular Programming
