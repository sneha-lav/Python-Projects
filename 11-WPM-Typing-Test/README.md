# TypeRush ⌨️⚡

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

TypeRush is a command-line typing speed tester built with Python. Players type randomly selected sentences as quickly and accurately as possible while the application measures their typing speed (Words Per Minute) and accuracy.

---

## Features

- Random typing prompts
- Words Per Minute (WPM) calculation
- Accuracy calculation
- Time tracking
- Replay option
- Modular code organization

---

## Concepts Practiced

- Time Module
- Random Module
- String Manipulation
- User Input
- Functions
- Modular Programming
