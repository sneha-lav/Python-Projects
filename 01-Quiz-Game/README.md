# Quiz Game

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Easy-success)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)


A command-line quiz application developed in Python that tests the user's knowledge through a series of multiple-choice questions. This project focuses on fundamental Python concepts such as variables, user input, conditional statements, loops, and score tracking.

---

## Features

- Interactive command-line interface
- Multiple quiz questions
- Score calculation
- Input validation
- Simple and beginner-friendly implementation

---

## Concepts Practiced

- Variables
- Data Types
- User Input
- Conditional Statements
- Loops
- Functions
- String Manipulation

## How to Run

Clone the repository and navigate to the project folder.

```bash
cd 01-Quiz-Game
```

Run the program using:

```bash
py main.py
```
