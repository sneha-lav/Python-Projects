# WakeUp ⏰

![Python](https://img.shields.io/badge/Python-3.14-blue?logo=python)
![Difficulty](https://img.shields.io/badge/Difficulty-Intermediate-yellow)
![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

WakeUp is a command-line alarm clock built with Python that allows users to schedule alarms for a specific time. The application continuously monitors the system clock and plays an alarm sound when the target time is reached.

---

## Features

- Set alarms using 24-hour format
- Real-time clock monitoring
- Audio notification
- Input validation
- Replay option
- Modular code organization

---

## Concepts Practiced

- Date & Time Module
- Loops
- Functions
- File Handling
- User Input
- Modular Programming
